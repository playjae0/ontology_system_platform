## 2. 만들 것

- **질의 탭**(명세 §6.1): 질문 칸 · 상태 줄(묻는 동안 `/api/status`를 0.4~1초마다) · 칸 일곱(ⓐ~ⓖ) · 경로 배지 · 미스·잘림 알림 · LLM 배지.
  - 칸마다 응답에 있는 것만 싣는다 — 화면이 고르거나 다시 세지 않는다. 시스템 뷰어 `cli/viewer/static/query.js`가 같은 묶음을 어떻게 싣는지 참고해도 된다(그리기 코드).
  - 노드 근거 청크의 본문은 `chunks`·`related`(있을 때만)·`doc_search`에서 `chunk_id`로 찾는다.
  - 요청은 한 번에 한 건(묻는 중에는 버튼을 막는다).
- **겹쳐 보기**: 사전 링킹 노드 · LLM이 고른 노드(`method` = `embed+llm`) · 확장으로 닿은 노드(`trace.hops[].nodes`)를 서로 다른 색으로, 경로 엣지(`trace.hops[].edges`)는 굵게.
  한 노드가 링킹과 확장 둘 다에 있으면 링킹 색. sigma 리듀서만 바꾼다 — 배치를 다시 하지 않는다. 새 질의마다 지우고 다시 칠한다.
  칠할 노드가 화면에 숨겨져 있으면(연결 없는 노드 등) 「화면에 없는 노드 n개」로 알린다.
- **노드 상세에 더할 것**(명세 §5.5 [P2]): `/api/node/<id>`의 근거 청크·닻까지의 길·문서마다 붙은 자리 ·
  나온 문서(`docs`에서 `seed` 제외)를 누르면 문서 패널 · 「이 노드로 질문」(질문 칸에 이름을 넣고 질의 탭으로 · 전송은 사람이).
- **문서 패널**(명세 §6.2) · **연결 현황 탭**(명세 §6.3).
- **칸 확인**: 질의·진행·노드·문서·깔때기 응답에 `X-Platform-Missing`이 오면 그 화면에 오류 카드(P1과 같은 방식 · 오류 응답은 확인하지 않는다).
- **오류**: 서버가 `{"error": …}`이나 HTTP ≥ 400을 주면 그 문면을 그대로 오류 카드로. 요청이 닿지 않으면 그 사실을.

## 3. 완료판정 — 전부 실행으로 (`verify/`에 스크립트)

- ⓐ **화면 = 응답**: 시험 문항 12개 각각에서 화면 칸의 항목 수 = 응답 목록 길이 — ⓐ `trace.linking` · ⓑ `trace.hops[].edges`(표시 상한을 두면 「n개 더」 포함) ·
  ⓒ `trace.facts` · ⓓ `trace.collection` · ⓔ `trace.doc_search` · ⓖ `records`. 쓴 것 표시 수 = `used`가 참인 수.
- ⓑ **겹쳐 보기**: 칠한 노드 집합 = `trace.linking`의 노드 ∪ `trace.hops[].nodes` · 둘 다에 있는 노드는 링킹 색 · 굵은 엣지 = `trace.hops[].edges` ·
  질의 전후로 노드 좌표 변화 0(배치를 다시 하지 않았다).
- ⓒ **상태 줄**: 묻는 동안 상태 줄이 뜨고, 끝나면 지난 단계 표시(`query.seen`)와 「끝」이 보인다.
  (개발 mock은 질의가 수십 ms라 중간 단계는 잡히지 않아도 된다 — 단계를 따라 바뀌는 것은 사내 실호출에서 사용자가 본다.)
- ⓓ **오류**: 빈 질문은 서버 문면(`q가 비었다`)이 그대로 뜬다 · 시스템 서버를 일부러 끈 뒤 물으면 중계의 502 문면이 그대로 뜬다.
- ⓔ **미스**: `trace.linking`이 빈 문항에서 링킹 칸이 비고, 미스 알림이 뜨고, 그래프 강조가 0이다.
- ⓕ **노드 상세의 근거**: 노드를 누르면 근거 청크 수 = `/api/node/<id>`의 `evidence` 수 · 닻까지의 길 단계 수 = `anchor_path.steps` 수.
- ⓖ **문서**: 나온 문서를 누르면 문서 패널이 뜨고 `tally`·`rows`·노드 수가 `/api/doc` 응답과 같다 · `raw_rel`이 없으면 안내 문장이 뜬다
  (개발 표본은 전부 `raw_rel` 없음 — 원본 열기는 사내에서 확인) · `/raw/없는/파일.xlsx`를 중계로 부르면 시스템의 404 문면이 그대로 온다.
- ⓗ **연결 현황**: 표의 행 수 = `funnel.rows` 수 · 합계 줄 = `funnel.total` · orphan 카드 수 = `funnel.orphans` 수 · 정의 문장이 표 위에 있다.
- ⓘ **이 노드로 질문**: 질문 칸에 그 노드 이름이 들어가고, 전송은 되지 않는다(`/api/query` 요청 0).
- ⓙ **쓰기 0**: P1 ⓙ와 같은 확인 — 시스템 상태 폴더 `data/`·`registry/`·`layers/` 해시 그대로 · 시스템 폴더 `git status --porcelain` 빈 출력.
- ⓚ **화면 캡처 둘**(개발 표본 — 「mock」 표시): 질의 결과 + 겹쳐 보기 · 연결 현황. 보고에 경로를 적는다.

## 2. 만들 것

- **① 문서별 노드 끄고 켜기**(명세 §5.3): 왼쪽 칸 「문서」 — `docs`에 나온 문서 id(`seed` 제외 · 이름 순 · 문서마다 노드 수)와 체크 · 「전부 켜기」 · 「전부 끄기」.
  골격이 아닌 노드는 `docs` 중 켜진 문서가 하나라도 있으면 보인다. 골격은 늘 보인다. 기본은 전부 켜짐. 문서 이름을 누르면 문서 패널(P2의 그것).
- **② 축 값 거르기**: layer · status · tier · polarity 중 값이 12개 이하인 축마다 값 체크(값마다 노드 수). 끄면 그 값의 골격 밖 노드가 빠진다. 카테고리는 넣지 않는다(깊이 표가 맡는다).
- **③ 연결 없는 노드 보이기**: 「연결 없는 노드 n개 보이기」(n = `edgeless` + `island`) 토글 — 켜면 보이는 노드에 더한다. 지금의 「…개는 숨겼다」 글(전제 9)을 이 토글로 바꾼다.
- **④ 보이기 판정 한 자리**: 보이는 노드 = (P3 `visibleNodes` ∪ 연결 없는 노드[토글이 켜졌을 때]) − 거른 노드(문서 · 축 값 — 골격 제외).
  그리기 · 머리 줄 수 · 깊이 표 수 · 범례 · 찾기 수 · 화면에 없는 노드 수가 전부 이 하나를 쓴다. 빠질 때는 빠지기만(다시 배치 없음) · 늘 때는 P3 ⑤ 그대로.
- **⑤ 노드 상세**(명세 §5.5 [P4]): 값 줄(`values` — 있을 때만 · 줄마다) · 원 레코드(`record` — 있을 때만 · 접은 JSON).
- **⑥ P3 확인 고침**(명세 §8 2026-11-18):
  - ⓒ — 판정에서 뺀다. 걸음 수치와 평균만 찍는다(「동작 확인 · 판정은 사내 손맛」).
  - ⓔ — 새 노드 ≤ 기존 노드인 펼침(지금 ⓔ′ 자리)에서 「먼 기존 노드 평균 이동 < 반경의 2% · 연결 쌍 ÷ 비연결 쌍 < 0.5」로 판정한다.
    많이 펼친 판(새 > 기존 — 지금 ⓔ 자리)은 「배치 종류가 전체 배치(layout)였다」만 본다(명세 §5.1 B-02).
  - `p16_drag.py` — 안쪽 `p15_drag.py`의 종료 코드가 0이 아니면 그 표준 출력 끝 40줄과 표준 오류를 그대로 찍는다(P3에서 한 번 있었던 간헐 실패의 원인을 보려는 것 — 고치지는 않는다).
- **장부**: BLOCKERS B-02를 「A로 결정 · 명세 §5.1」로 닫는다 · DECISIONS P-46부터 · PROGRESS 맨 위.

## 3. 완료판정 — 전부 실행으로 (`verify/p4_filters.py` 하나 · mock)

- ⓐ **문서 목록**: 목록의 문서와 수 = `/api/graph`에서 따로 센 것(골격 밖 노드의 `docs` 기준).
- ⓑ **문서 끄기**: 노드가 가장 많은 문서 하나를 끔 → 보이는 노드 = 이전 − {골격 밖이고 켜진 문서가 `docs`에 없는 노드}(따로 셈과 같다) · 남은 노드 좌표 변화 0 ·
  다시 켜면 이전 집합 · 「전부 끄기」 → 골격만 · 「전부 켜기」 → 이전 집합.
- ⓒ **문서 이름 누르기** → 문서 패널이 그 `doc_id`로 열린다.
- ⓓ **축 값**: layer 축에서 값 하나를 끔 → 그 층의 골격 밖 노드가 빠진다(따로 셈과 같다) · 다시 켜면 이전 집합.
- ⓔ **연결 없는 노드**: `/api/graph` 응답을 가로채(Playwright `route`) 엣지 없는 노드 하나를 `nodes`와 `detached.edgeless`에 넣으면 →
  토글 글 「연결 없는 노드 1개 보이기」 · 켜면 그 노드가 보인다 · 끄면 빠진다.
- ⓕ **수가 같다**: 문서 하나를 끈 상태에서 머리 줄 노드 수 = 보이는 노드 수 · 깊이 표의 수 = 그린 수 · 범례 합 = 보이는 노드 수.
- ⓖ **상세**: `values`가 있는 노드를 누르면 값 줄 수 = `values` 길이 · 원 레코드를 펼친 JSON = `/api/node`의 `record` · `values`가 없는 노드에는 값 칸이 없다.
- ⓗ **P3 확인 고침**: `python verify/p3_explore.py` → 종료 코드 0(ⓒ는 수치만 · ⓔ는 새 노드 ≤ 기존 판에서 판정 · 많이 펼친 판은 전체 배치였음).
- ⓘ **회귀**: P1 확인 셋 · `p2_query.py` · `p16_drag.py --ref <전제 13의 파일>` 전부 PASS(그리기 · 배치를 바꾸지 않았다).
- ⓙ **쓰기 0 · 외부 요청 0**: P1 ⓙ·ⓚ와 같은 확인.
- ⓚ **화면 캡처 하나**(mock — 「mock」 띠): 문서 하나를 끈 화면. 보고에 경로.

**mock 표본의 개수를 세는 어서션은 만들지 않는다**(CLAUDE.md §5) — 화면과 응답(따로 셈)이 같은지, 동작이 일어나는지만 잰다.
